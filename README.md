# Cybersecurity_Awareness_ChatBot_Part2
A desktop cybersecurity awareness chatbot developed using C# and WPF in Visual Studio.
Cybersecurity Awareness Chatbot is designed to educate users about cybersecurity topics such as passwords, phishing, malware, scams, and privacy.

The chatbot uses keyword recognition, random responses, sentiment detection, and memory features to provide an interactive learning experience.

## Features
GUI Interface using WPF
Keyword Recognition
Random Responses
Sentiment Detection
Memory Feature
Welcome Audio
ASCII Art Display
Dynamic Cybersecurity Tips
Collections and Delegates
